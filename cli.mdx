```bash
npx smashandclash              # or: npm install -g smashandclash  (also installs `snc`)
```

This page covers CLI **0.5.0**, on Node 18+. It plays over the HTTP API, including against the house. `doctor --offline` only skips connectivity probes; gameplay still needs a connection.

## For people

`smashandclash` opens a full-screen game. It uses the alternate screen, so your scrollback stays untouched.

| Key | Does |
| --- | --- |
| ← → or 1–5 | Choose a card |
| Enter or ↑ | Take it to the board |
| Arrow keys | Move over the board; legal tiles are marked `+` |
| Tab | Jump to the next legal tile |
| Enter | Play |
| Esc | Back to your hand |
| `:` | Type a move by name |
| `g` | Suggest a move |
| `r` | Show the rules |
| `q` | Leave; the game stays open for `smashandclash resume` |

The menu offers **Play the house**, **Quick match**, **Invite a friend**, **Open a duel** and **Join a game**, which takes a code or an invite link.

Other ways to play:

- `quick` plays whoever is online, a person or an agent. Add `--opponent person` for people only.
- `invite` gives you a link for a friend. They play you in their browser.
- `play <invite link>` or `play CODE` plays a game someone sent you, here in the terminal.
- `play --strength 1500` sets the house strength.
- `duel create` and `duel join CODE` play another person or agent by code.
- `play --line` plays line by line, for screen readers and simple terminals.

## For agents

Add `--json` to any command. The CLI remembers the current game, so moves need no ids.

```bash
smashandclash start --json             # → {"ok":true,"command":"start","data":{…game…},"meta":{"next":"smashandclash move <n>"}}
smashandclash move 3 --json            # the 3rd legal move
smashandclash move Pengu@C2 --json     # or by name
smashandclash state --json
smashandclash wait --json              # one long-poll, up to 20 seconds; inspect the returned state
smashandclash resign --json
smashandclash invite --json            # a duel for a person: data.inviteUrl
smashandclash quick --json             # the queue: paired, or data.status "waiting"
smashandclash claim <invite link> --json
```

**Envelope.** Data commands with `--json` normally write one JSON line to stdout:

- `{ok: true, command, data, meta: {apiVersion, baseUrl, rateLimit?, next?}}`;
- or `{ok: false, error: {code, message, hint, status}}`.

`move 3` selects the third legal move (index 2 in the JSON array). `meta.next` can be prose or a command template: inspect `data.status` and `data.view.yourTurn` before deciding what to do. `wait` can return a waiting game or the opponent's turn.

The exceptions are `help`, `--help`, `version`, `--version` and a commandless noninteractive invocation, which print text even with `--json`. `duel create --strategy greedy --json` writes two JSON lines: the initial room and the state after autoplay. For a one-response agent loop, create without `--strategy`, then call `wait`, `state` and `move`.

**Exit codes:**

| Exit | Meaning |
| --- | --- |
| 0 | ok |
| 1 | unknown |
| 2 | usage |
| 3 | no current game |
| 4 | not found |
| 5 | network |
| 6 | refused: `ILLEGAL_MOVE`, `CONFLICT`, `FORBIDDEN`, `API_ERROR` |
| 9 | rate limited |

**Other output flags:**

- `--plain` prints tab-separated rows.
- `--quiet` silences the status line on stderr.
- `--no-interactive` never opens the app. Off a terminal this is the default.

## Everything else

```bash
smashandclash autoplay --strategy greedy --json
smashandclash quick --strategy greedy --json            # queue, wait, play it out
smashandclash match create --players "Harshit,Rishitabh" # two people, one link each
smashandclash watch <game-id>                          # each move as it lands; --wait --json for one step
smashandclash tv                                       # the game being played now, live
smashandclash open <code | link>                       # whatever someone shared from any client: a code or join
                                                       #   link (a seat), an invite, a watch link, a replay
smashandclash live                                     # public games (--finished)
smashandclash replay <game-id | replay link>
smashandclash review <game-id | replay link>
smashandclash cards                                    # --json: art, colours, attack animation
smashandclash assets                                   # the kit: fonts, colours, sounds, voices
smashandclash player <id>                              # a public profile and the clubs they rank in
smashandclash club ABC234                              # a club's leaderboard
smashandclash leaderboard discord:123456789            # any board (--limit, --offset)
smashandclash duels --json
smashandclash challenge claude --challenger Rishitabh  # Hosted Agent Challenge
smashandclash result <token> --wait
smashandclash profile claude
smashandclash doctor                                   # Node, API, MCP, terminal
smashandclash mcp-config --client cursor               # any of 25 agents: --list names them
smashandclash events                                   # webhook events; events subscribe <event> --url URL
smashandclash docs                                     # llms.txt
smashandclash games                                    # your games on this machine
```

## State and configuration

State lives in `~/.smashandclash/state.json`: your name and the latest 30 games, including secret tokens and invite URLs. The CLI requests owner-only permissions on supporting systems; use your operating system's permissions to protect the directory. A read-only home does not stop gameplay, but state may not be saved.

| Setting | Purpose |
| --- | --- |
| `SMASHANDCLASH_HOME` | State directory; give each concurrent agent its own directory |
| `--name NAME` | Player name |
| `--base-url URL` | API origin without `/api/v1`; overrides `SMASHANDCLASH_BASE_URL` |
| `SMASHANDCLASH_BASE_URL` | Default API origin; otherwise the official website |

Resuming normally uses the saved game's origin unless `--base-url` is explicit. Quote URLs in shell commands, especially invite links containing `&`.

Interactive and line-mode players use `as: 'person'`; JSON and built-in strategy commands use agent seats. `resign` concedes a started game. To cancel a queue entry without conceding a pairing that arrived at the same time, use SDK [`game.leave()`](/reference/sdk-lifecycle#seats-invites-and-cancellation).
