## In a browser

From **0.2.1**, the SDK runs in a browser with no setup: import it from your bundle (or serve its single file, `dist/index.js`) and call `new SmashAndClash()`. The API accepts cross-origin calls.

Version 0.2.0 needs your own `fetch` in a browser. It sends an `X-SDK` header that older API deployments refused cross-origin, and it called `fetch` as a method, which a browser rejects. Pass a plain function that drops the header:

```ts
const sc = new SmashAndClash({
  fetch: (url, init = {}) => {
    const { 'x-sdk': _, ...headers } = (init.headers ?? {}) as Record<string, string>;
    return fetch(url, { ...init, headers });
  },
});
```

## Games

```ts
const game = await sc.games.startHouse({ name: 'My Agent', strength: 1200, ruleset: 'mutators' });

game.view;          // your hand, the board, legalMoves
game.legalMoves;    // string[]
game.yourTurn;      // boolean
await game.play('Pengu@C2');           // the house has answered when this resolves
await game.playOut(greedyMove);        // or: (view, seat) => moveName, to the end
game.over; game.winner;                // 'you' | 'opponent' | 'draw'
game.replayUrl;
```

| Method | Does |
| --- | --- |
| `sc.games.startHouse(o)` | A game against the house opponent |
| `sc.games.createDuel(o)` / `joinDuel(code, o)` | Duels by code; share `game.code` |
| `sc.games.createDuel({ opponent: 'person' })` | A duel against a person: send `game.inviteUrl` |
| `sc.games.quickMatch({ opponent })` | The online queue: paired now, or `game.waiting` |
| `sc.games.createMatch({ players })` | A match between two people: `match.invites.A` / `.B` |
| `sc.games.claim(inviteUrl, o)` | Take the seat an invite opens |
| `sc.games.open(anything, o)` | Whatever a player shared from any client: a code or join link (a seat; a full room opens to watch), an invite, a watch link, a replay, a challenge. See [one game, every client](/clients) |
| `sc.games.byCode(code)` | The game a room code belongs to, as a spectator sees it |
| `parseLink(text)` / `joinLink(code)` / `watchLink(id)` | Read any client's code or link / build a join link / build a watch link |
| `sc.games.resume(id, playerToken)` | Pick a game up again |
| `sc.games.watch(id)` / `follow(id, o)` / `spectate(id)` | The public board / the next change / every change (async iterator) |
| `sc.games.feed(id, o)` | Every move as it lands, with its public events and the board after it (async iterator): [watch games](/play/watch) |
| `sc.games.watchSync(id, o)` | A spectator's sync: the table now and every move since `since`, hands as counts |
| `sc.games.live(o)` / `featured()` / `openDuels()` | Public games to watch / the game to stream now / duels waiting by code |
| `sc.games.replay(id)` / `review(id)` | A finished game, move by move / its Game Review |
| `sc.replays.read(url)` / `review(url)` | The same for a shared replay link |
| `sc.cards()` | The deck, with each character's art, colours and attack animation |
| `game.refresh()` / `waitForTurn(s)` / `waitForOpponent()` / `resign()` | Re-read / wait for your turn / wait for the other player / resign |
| `game.leave()` | Leave a room nobody joined, or the queue; never resigns a game that started (a 409: play it) |
| `game.joinLink` / `game.watchLink` | The link that opens your room on any client / the game's live page |
| `game.sync(o)` | Your seat's state and events, to [draw your own board](/play/board) |

Pass `as: 'person'` when a person plays the seat, and from **0.5.0** their `rating` (their ELO, as your app keeps it) to `createDuel`, `joinDuel`, `quickMatch` and `claim`. Every game carries `playerKinds` (who plays each seat), `ratings` (when the players brought them) and `clients` (the client each seat plays from: `smashandclash.in`, `smashandclash-cli`, `mcp`, or your app's `client` name).

On your turn `game.view.moves` lists the legal moves as data (`{ name, type, cardId, cell, … }`), and every card in `game.view` carries its `cardId`. See [Move names](/play/moves#moves-as-data).

## Build your own client

```ts
const cards = await sc.cards();   // image, art, colorHex, versus, animation
const kit = await sc.assets();    // brand, fonts, card geometry, colours, attack timing, sounds, voices
```

| Method | Does |
| --- | --- |
| `sc.cards()` | Every card: its face, its frameless art, colours, VS art and [attack drawings](/build/animation) |
| `sc.assets()` | The [kit](/build/overview#the-kit): brand, fonts, card back and template, badge colours, [sound](/build/sound) |
| `cellToRC(cell)` / `rcToCell(rc)` | `'C2'` ↔ `{ r: 1, c: 2 }` |
| `boardSides(card, seat)` | A card's sides by compass, turned round for seat B |

The art and audio are free to use in clients built for Smash&Clash, never to present as your own: see [Using the art and audio](/build/overview#using-the-art-and-audio).

## Players and leaderboards

```ts
const { player, clubs } = await sc.players.get('p-k3j9x2m1qa');
const board = await sc.clubs.get('ABC234', { limit: 20 });
const server = await sc.leaderboards.get('discord:123456789');
```

| Method | Does |
| --- | --- |
| `sc.players.get(id)` | A player's public profile and the clubs they rank in |
| `sc.clubs.get(code, o)` | A club's leaderboard, best first (`limit`, `offset`) |
| `sc.leaderboards.get(id, o)` | Any board: `club:<CODE>`, `discord:<id>`, `whop:<id>` |

See [Players and leaderboards](/players).

## People and matchmaking

```ts
// your agent against a person
const duel = await sc.games.createDuel({ name: 'Claude', opponent: 'person', opponentName: 'Ada' });
send(ada, duel.inviteUrl);
await duel.waitForOpponent();
await duel.playOut(greedyMove);

// two people, hosted
const match = await sc.games.createMatch({ players: ['Ada', 'Grace'] });
const end = await match.waitForEnd();
const review = await match.review();

// whoever is waiting
const game = await sc.games.quickMatch({ opponent: 'any' });
```

`game.playerToken` is your seat: store it like a password.

## Hosted Agent Challenges

```ts
const ch = await sc.challenges.create({ agent: 'claude', challenger: 'Ada' });
const done = await sc.challenges.waitForResult(ch.token);   // polls every 15 s, up to 30 min
await sc.agents.profile('claude');
await sc.agents.matches('claude', { challenger: 'Ada', limit: 20 });
```

## Errors, retries, limits

- Failures throw `SmashAndClashError`, which carries `status`, `code`, `message` and `hint`.
  - An illegal move is a `422`, and its message lists the legal moves.
  - Not your turn is a `409`, and so is the replay of a game that isn't over.
- A `429` is retried after its `Retry-After`, twice by default. Set `retries: 0` to turn that off.
- From **0.4.1**, a dropped connection is retried too, where that's safe:
  - Reads are tried again, after 0.25 s and then 0.75 s, and so is any call whose connection never opened.
  - A move or a resignation is sent again only if the game shows it didn't land, so nothing is played twice.
  - Calls that make something (a game, a duel, a challenge) aren't sent twice.
  - When the retries run out, the network's own `TypeError` is thrown. `isNetworkError(e)` tells you it was one.
- `sc.http.rateLimit` is what the last response reported, e.g. `{ policy: 'play', remaining: 117, resetSeconds: 42 }`.

## Name your app

From **0.2.2**, pass `client` to say which app is calling: `new SmashAndClash({ client: 'my-bot/1.2' })`. It is sent after the SDK's own name in the `X-SDK` header (`smashandclash-sdk/0.2.2 my-bot/1.2`), so we can see which apps use the API. Use letters, digits and `. _ + - /`, up to 64 characters; anything else is left out. The CLI names itself `smashandclash-cli/<version>` this way.

## Examples

- **[Tournament Organizer](https://github.com/smashandclash/tournament-organizer):** an open-source $SMASH tournament platform built on this SDK. Players pay a $SMASH entry per match into a pool, get paired fairly, and play right in the app (`games.createMatch`, `games.claim`, `game.play`, `game.sync`); results come from `games.watch`, and the most wins takes the pool, paid out on Solana. It also uses practice (`games.startHouse`, `quickMatch`, duels), live games (`games.live`, `games.follow`), replays and reviews, `cards()`, `rules()`, AI agent challenges and the bots (`greedyMove`). Its *Built with the SDK* page maps every call to its screen. Solana devnet by default; paid tournaments fall under [Section 14A of the Terms](https://www.smashandclash.in/terms#developers).
- **[Smash&Clash on Delta, DS and GBA](https://github.com/smashandclash/delta):** Smash&Clash on retro handhelds. A Nintendo DS game in C that plays online in Delta, melonDS and on real hardware: it speaks this SDK's API over TLS itself, through a C port of the SDK's calls under the same names (`games.startHouse`, `game.play`, `game.waitForTurn`, `games.joinDuel`, `game.sync`, `games.review`). And a Game Boy Advance game with no network at all that plays through the SDK itself: an mGBA script carries each call to a small Node bridge that makes it with `@smashandclash/sdk`. Delta skins and headless emulator tests included.
- **[Smash&Clash on the PSP](https://github.com/smashandclash/ppsspp):** the whole game on a PSP, in PPSSPP or on real hardware, drawn in 3D by the PSP's GPU. The same C client as the DS: games against the house, quick match, invite QR codes, play by code against a DS, a GBA or the CLI, the Game Review and replays.
- **[Smash&Clash for Minecraft](https://github.com/smashandclash/minecraft):** the game on a table in a Minecraft world, for Java Edition (a Fabric mod) and Bedrock Edition (an add-on). The board, the cards and the deck are real things in the world that everyone nearby sees; your hand is in your inventory, and the website's animations play on the board, beat for beat. The asset pipeline reads the deck and the art through the SDK (`cards()`, `assets()`). Bedrock runs this SDK itself, bundled into the behavior pack with `fetch` over `@minecraft/server-net`; the Java mod speaks the same calls under the same names, in Java (`games.startHouse`, `quickMatch`, `createDuel`, `joinDuel`, `game.sync`, `game.play`). House games, quick match and room codes, against anyone on any client.
- **[Smash&Clash on tldraw](https://github.com/smashandclash/tldraw):** a complete client that runs on a tldraw board, built on this SDK. It covers games against the house, quick match, invite links, effects and hops, and the Game Review. The repo also has a minimal board client in about 140 lines, and five Node scripts: play the house, invite a person, [draw your own board](/play/board), watch live, and review a game.
