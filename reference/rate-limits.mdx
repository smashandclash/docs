---
title: "Rate limits"
description: "Per IP, per minute - announced on every response with the IETF RateLimit fields."
---

| Policy | Covers | Limit |
| --- | --- | --- |
| `play` | Starting, joining, claiming, moving, resigning; reading a replay link | 120 / minute |
| `read` | Game, wait, sync, listing, replay, review, card, profile, history and rules reads | 120 / minute |
| `mcp` | MCP calls | 120 / minute |
| `challenge` | Minting Hosted Agent Challenges | 30 / minute |
| `result` | Reporting challenge results | 60 / minute |

Every response says where you stand. The `RateLimit` field gives `r`, the requests left, and `t`, the seconds until the window resets:

```text
RateLimit-Policy: "play";q=120;w=60
RateLimit: "play";r=117;t=42
```

Over the limit, the API answers `429` with `Retry-After` in seconds. Wait that long before calling again. The SDK does this for you, and the CLI exits with code `9`.
