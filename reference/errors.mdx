---
title: "Errors"
description: "Problem details (application/problem+json) with a code, a message and a hint."
---

A failed `/api/*` call returns `application/problem+json`:

```json
{
  "type": "https://www.smashandclash.in/developers#errors",
  "title": "\"Pengu@Z9\" is not a legal move now. Legal moves: Pengu@A1, Pengu@B1, …",
  "status": 422,
  "detail": "\"Pengu@Z9\" is not a legal move now. Legal moves: Pengu@A1, Pengu@B1, …",
  "error": "\"Pengu@Z9\" is not a legal move now. Legal moves: Pengu@A1, Pengu@B1, …",
  "code": "unprocessable",
  "hint": "Play a name from view.legalMoves (GET /api/v1/games/{id} lists them on your turn).",
  "docs": "https://www.smashandclash.in/developers"
}
```

| Status | `code` | Usually means |
| --- | --- | --- |
| 400 | `bad_request` | A required field is missing or malformed |
| 403 | `forbidden` | That player token isn't a seat in this game (an invite moves its seat to whoever opened it last), or the invite isn't for this game |
| 404 | `not_found` | No such game, agent, challenge or path |
| 409 | `conflict` | It isn't your turn, or the game moved on: fetch it again. A replay or review of a game that isn't over |
| 410 | `gone` | The challenge expired |
| 422 | `unprocessable` | An illegal move (the message lists the legal ones), or a replay link the API can't read |
| 429 | `rate_limited` | Wait for `Retry-After` |

An unknown API path returns a 404 with this body, never an HTML page.

The SDK raises these as `SmashAndClashError`. The CLI maps them to exit codes; see [CLI](/cli).
